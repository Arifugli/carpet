# Заказ, адрес и замеры — 0.7.0

Новый заказ содержит вид и количество изделий. Начальные ставки: **ковры — 12 000 сум/м²; одеяло и тушак — 30 000 сум/шт.** Надбавки, пенсионная скидка, промокоды и доставка действуют по настройкам филиала. Каждое физическое изделие получает свою QR-метку. Ставка и единица фиксируются при создании заказа; изменение тарифа применяется к следующим заказам.

Оператор выбирает филиал, область, район/город, улицу, дом и квартиру. Для частного дома есть переключатель «без квартиры». Ориентир необязателен. Координаты вручную не вводятся. Доступны 14 регионов Узбекистана; справочник Ферганской области содержит 15 районов и 4 города. Для остальных областей районы пока не заполнены: улица и дом остаются обязательными. Сохранённый структурированный адрес можно выбрать повторно; старый текстовый адрес остаётся в истории, его поля нужно заполнить при новом заказе.

У оператора нет полей длины и ширины. Попытка передать замеры через API создания заказа также отклоняется. До замера ковров водителем итог обозначается «Стоимость после замера водителем»; платежи, скидки и акт с итоговой ценой недоступны. Поштучные изделия рассчитываются сразу. Неизвестная площадь не резервируется как выдуманное количество м²: при планировании нужно учитывать заказы, ожидающие замера.

Водитель открывает своё задание → «Замер и стоимость». Измеряет ковры (метры с точностью до сантиметра), подтверждает каждую штуку одеяла/тушака и нажимает «Сохранить и рассчитать». Сервер рассчитывает стоимость по сохранённой ставке заказа. Сразу видны цена и прогресс замеров/фото. Следующее изделие без фото автоматически предлагается при открытии «Фото изделий».

После загрузки фото каждого изделия водитель нажимает **«Забрал»**. Заказ остаётся у водителя, замер и цена фиксируются. После фактической доставки нажимает **«Передал цеху»**. Заказ появляется в очереди цеха как «Ожидает приёма цехом». Сотрудник цеха нажимает **«Принял»**, затем **«Замеры / количество»**, самостоятельно измеряет ковры и подтверждает каждую штуку. Только после подтверждения всех изделий доступен переход в стирку. Дальнейшие этапы сохранены.

Цех видит замер водителя, но форма нового замера не заполняется его числами. Разница площади более 0,01 м² требует причины. Доступны автор, время и история исправлений. Повторный замер цеха **не изменяет согласованную с клиентом цену автоматически**, включая уже оплаченный заказ. История приёма и передачи неизменяема. Замер водителя нельзя исправить после «Забрал», оплаты или скидки; цех может фиксировать фактическую площадь до стирки независимо от оплаты.

Фотографии связаны с клиентом, заказом и конкретным изделием. В карточке заказа доступны «Посмотреть фото заказа» и «Посмотреть все фото клиента», в карточке клиента — общий просмотр. Галереи по умолчанию закрыты; ссылки запрашиваются при открытии. Любой активный сотрудник филиала может просматривать его фотографии независимо от своей рабочей роли. Другие филиалы закрыты, администратор/руководитель сохраняют общий доступ. Из корзины фото не показываются. Используется приватный bucket и короткоживущие ссылки. Загрузка проверяется в Storage до регистрации фото; при ошибке снимок остаётся в очереди с понятным статусом, «Забрал» недоступно до фактической загрузки всех необходимых снимков.

В заданиях водителя есть «Показать карту с маршрутом». Выбор сохраняется отдельно для каждого водителя. Включение загружает дорожный маршрут Яндекс Карт; начальную точку можно выбрать на карте или получить кнопкой «Маршрут от моего местоположения». Геолокация запрашивается только по нажатию и не сохраняется на сервере. При отказе доступен ручной выбор и переход в навигацию. Выключение удаляет карту; письменный адрес всегда остаётся. В карты передаётся адрес дома без квартиры и ориентира. У остальных ролей этого переключателя нет.

География: [территории Ферганской области](https://gov.uz/ru/ferghana/departments/regional), [регионы Узбекистана](https://www.postda.uz/ru/hududlar/). Карты: [виджеты Яндекса](https://yandex.ru/dev/maps/mapstools/), [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started).

## Обновление

После миграций 0001–0011 применить **0012_driver_intake.sql**, затем развернуть API и оболочку 0.7.0. Предыдущие миграции не изменяются. Новая миграция не меняет прежние суммы, размеры и фото. Для заказов, уже отмеченных «Забрал» в 0.6, но ещё без замеров/приёмки цеха, восстанавливается этап «Изделия у водителя»: можно закончить замер, рассчитать цену и передать цеху. Такие задания видны водителю независимо от выбранной даты, пока передача не завершена. Фактические старые статусы и история не переписываются. Бесплатный Render web сохраняется.

Проверки выполняются в локальном PostgreSQL PGlite, через HTTP и DOM. Они проверяют адрес, единицы, цену, роли, неизменность истории, приёмку и переключатель карты. Фактический дорожный маршрут и геолокацию на телефоне необходимо проверить на месте: внешний сервис сам распознаёт адрес и строит дорогу. Автоматизированный браузер в текущем локальном окружении не запускался.

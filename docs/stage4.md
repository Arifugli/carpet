# Сохранённые дополнительные функции

Платежи и возвраты, подтверждение безналичных оплат, касса/сверка, онлайн-счета Payme/Click, скидки, акты с OTP, претензии/компенсации, склад материалов/нормы и начисления сохраняются. Источники данных и история остаются в PostgreSQL. Права текущих ролей — permissions.md; передача заказов — booking-measurements.md.

Приём оплаты driver доступен по его доступным оценённым заказам. Сверку, подтверждение, возвраты и расширенные настройки выполняет admin. Полное возмещение не снимает исторический след платежа и не разрешает удалить ранее оплаченный заказ.

Материалы списываются атомарно при приёмке мойщиком, по фактическим м²; при нехватке фаза не меняется, начисления не возникают. Повтор того же запроса не списывает и не начисляет повторно. Ставки версионируются; старые ставки прежних ролей остаются неактивными. Новые ставки производственных ролей настраивает admin, без автоматического переноса.

Отдельная перемывка по клиентской претензии остаётся административной операцией; её стадии не подменяют основной жизненный цикл заказа. Производственный возврат упаковщика идёт через warehouse → washing → packing с причиной и новым циклом фото-чека.

SLA формирует напоминания активным admin; opt-in клиента управляет отправкой сообщений. Outbox сохраняет lease/retry, подписи webhook и ограничение адресов. Фактическая отправка и SLA требуют worker; текущий бесплатный web не включает отдельный worker.

Импорт CSV/XLSX сохраняет preview/атомарный commit/ключ повтора; новые заказы требуют ФИО и структурированный адрес с областью/районом и изделиями без размеров. API выдаёт актуальный CSV-образец. Экспорт клиентов/отчётов, QR-этикетки, квитанции, телефония, теги/согласия и чёрный список сохраняются. Подключение действующих SMS/Telegram/платёжных аккаунтов проверяется отдельно в их окружениях; тесты используют контрактные адаптеры.

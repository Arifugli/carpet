# Текущая версия

0.8.0 реализует новый жизненный цикл заказа, шесть ролей, канбаны, собственные замеры склада, фото-чек упаковки, повторные доставки и SQL-агрегаты. Миграции 0001–0013 не изменены; добавлены 0014–0016.

Код и проверки выпускаются отдельным PR. Рабочее обновление — отдельное окно после подтверждённых резервных копий PostgreSQL и Storage. Без выполненной одноразовой очистки новый readiness не подтверждает запуск. Порядок — operations.md; принятые трактовки — decisions.md.

Районы остальных областей Узбекистана остаются будущим наполнением справочника; пока доступны территории Ферганской области. Новых платных ресурсов Render этот выпуск не создаёт.

# Администрирование

Admin создаёт сотрудников всех шести ролей, включая других admin, меняет профиль/филиал/активность, формирует ссылку восстановления доступа. Последний активный admin защищён. У driver обязательны один или несколько районов; допускается цвет #RRGGBB, по умолчанию #f9a8d4. Список районов и цвет изменяются тем же staff.update атомарно с профилем.

Сотрудники с прежними ролями сохраняются, но 0015 отключает их; role_reassignments хранит снимок. Администратор назначает новые роли вручную. Старый enum не очищается физически: CHECK запрещает активировать недействующую роль.

Редактирование и архивирование филиалов, сотрудников, тарифов, записей справочников, причин и шаблонов сохранено. Архив не удаляет историю или связи. Сотрудник восстанавливается неактивным; тариф изменяется новой версией. Ссылки с архивным филиалом не принимают новых назначений. Телефон филиала/сотрудника нормализуется в +998; ошибки выделяют поле без потери введённых данных.

Разделы admin: единый канбан, дополнительный «Заказы», управление, корзина/аудит, отчёты/Excel и прежние финансовые/служебные экраны. В списках сотрудников сведения о прежней роли могут оставаться как исторические данные для переназначения.

# Управление данными администратором

В «Управление» есть разделы «Сотрудники», «Филиалы», «Тарифы», «Справочники» и «Шаблоны уведомлений». На карточке доступны «Изменить» и «Удалить». Удаление подтверждается отдельной формой. «Показать удалённые» открывает архив и кнопку восстановления. Неактивная запись и удалённая запись различаются.

| Данные | Редактирование | Удаление и восстановление |
| --- | --- | --- |
| Сотрудник | Имя, телефон, одна из шести ролей, филиал, активность | Сразу теряет доступ к CRM; Auth-пользователь и история сохраняются. Восстанавливается неактивным; включение доступа — отдельное решение admin. |
| Филиал | Код, название, адрес, телефон, мощность и срок | Нельзя удалить/отключить при активных сотрудниках или незавершённых заказах. Сначала перенесите сотрудников и завершите работу. |
| Тариф | Название, цена, активность, дата новой версии | Архивируется только для выбранного филиала, включая запрет будущих запланированных цен. Восстановление вновь разрешает выбор действующей версии. Цены и снимки уже созданных заказов сохраняются. |
| Запись справочника | Названия, активность, параметры временного окна | Перестаёт предлагаться для новой работы, остаётся в истории. Вид, код и филиал сохраняются. Причины отказов общие для компании. |
| Шаблон | Код, канал, язык, текст, активность | Архивный шаблон выключен, его данные сохраняются; восстановление включает его обратно. Уже сформированная очередь сообщений не переписывается. |

Нельзя удалить собственную учётную запись или отключить последнего администратора. Назначенные водителю открытые заказы/визиты и открытые задачи сотрудника нужно сначала переназначить или завершить. Восстановленному сотруднику проверьте филиал и роль, затем явно включите «Активен».

Тариф редактируется новой версией. Дата по умолчанию означает применение при сохранении; можно указать будущую дату. История версий доступна под списком тарифов. Физическое удаление связанных записей не выполняется. Изменения, архивирование и восстановление сохраняют автора, время и состояния до/после в аудите.

Все операции проверяются API и SQL, доступны только admin и требуют Idempotency-Key. Архив нельзя обойти обычной активацией через прежнюю команду: сначала требуется восстановление. Матрица ролей не изменена, конструктор новых ролей не добавляется.

Нужна миграция 0010_admin_management.sql после 0009; исходные миграции не редактируются. /ready проверяет схему 10. Тариф Render остаётся Free, worker не создаётся.

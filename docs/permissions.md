# Права

Источник: `config/permissions.json`, SQL-копия в 0015. Активный профиль перечитывается на каждый запрос; роль из JWT/user_metadata не используется. Неактивные и выведенные из использования роли не получают доступ.

| Роль | Возможности |
|---|---|
| operator | Создание без замеров/фото; полный канбан филиала; отмена до доставки; клиенты, звонки, заявки, напоминания, претензии, запрос удаления |
| driver | Свой шестиколоночный канбан; самостоятельное взятие; замеры, фото, расчёт при заборе; передача складу; доставка/отложение/повтор; прежние оплаты по доступным заказам |
| warehouse | Только склад: приём, собственные замеры и комментарии расхождений, передача на мойку, дефекты |
| washer | Только мойка: приём, мойка, сушка, передача на упаковку, дефекты |
| packer | Только упаковка: приём, фото-чек, передача в готовые или возврат на склад с причиной, дефекты |
| admin | Канбан всех филиалов, создание/отмена, сотрудники включая admin, районы/цвет водителя, управление справочниками/филиалами/тарифами/шаблонами, корзина/аудит, все прежние финансы/отчёты/настройки |

Точные массивы разрешений проверяются тестом на совпадение с БД. Действия этапов дополнительно проверяют конкретную роль и текущий этап в RPC: общее право чтения их не разрешает. Admin не исполняет производственные шаги за сотрудников.

## Права, ранее отдельные для диспетчеризации и руководства

- Подтверждение безналичных оплат, возвраты, закрытие кассы, онлайн-счета и финансовые отчёты: admin. У driver сохраняется ранее существовавший приём оплат/своя касса.
- Все SQL-отчёты и Excel, выгрузка клиентов, склад материалов, ставки/начисления, скидки и разрешение претензий/компенсаций: admin.
- Ограничения расписания, подсказки маршрутов/мощности, интеграции и повтор outbox, настройка сотрудников/филиалов/тарифов/шаблонов: admin.
- Общие назначения водителя и ручное изменение статуса/планирование задания через прежние API: заблокированы. Водитель сам берёт забор и доставку.
- Напоминания другим сотрудникам и эскалации SLA: admin. Личные напоминания operator/driver сохранены.
- Отдельная перемывка по претензии: admin; новым производственным ролям прежние расширенные права не передаются. Возврат упаковщика по качеству выполняется новым графом через склад.

Доступ прямых клиентских ключей к таблицам закрыт GRANT и RLS. Новые таблицы включают RLS без клиентских политик; сервер получает права явно. Аудит неизменяемый; физическое удаление заказов запрещено, кроме одноразовой транзакции 0016.

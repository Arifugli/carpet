# Рабочие места и этапы

operator/admin: все десять колонок. warehouse: только «Склад». washer: только «Мойка». packer: только «Упаковка».

driver: новые (все в филиале), запланированный забор (свои), готовые (все в филиале), в пути (свои), доставлены (свои, за период), отложены (свои). Новые заказы закреплённых районов идут первыми и подсвечены розовым. Для готовых применяется настраиваемый admin цвет водителя, по умолчанию розовый. Отменённые и чужие личные задания не показываются.

В каждой колонке SQL считает число заказов, м² ковров, одеяла/тушаки в штуках и сумму. Фильтры: дата поступления на этап, вид изделия, цена от/до, район, водитель, оператор, ФИО/телефон/номер; admin может выбрать филиал. Заголовок включает все найденные заказы, независимо от страницы. Данные обновляются после действий и опрашиваются каждые 15 секунд, когда не открыта форма.

Дашборд admin «Заказы» использует когорту по дате создания: прошедшие мойку, доставленные, сейчас на мойке, готовые. Заказ, повторно прошедший мойку, считается один раз. Все показатели включают отдельные единицы, число заказов и денежные значения. Сумма означает согласованную стоимость услуги, а не поступления в кассу; стоимости видов изделий показаны без надбавок/доставки.

Без выбранного периода показываются все доступные заказы. Фильтр вида выбирает заказы, содержащие этот вид; суммы и количества включают весь их состав. При заданной цене ещё не оценённые заказы исключаются.

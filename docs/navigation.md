# Дополнительные разделы CRM

Меню «Разделы» (ранее «Ещё») содержит инструменты, которыми пользуются по ситуации. Основной ежедневный маршрут остаётся в «Главная», «Задачи», «Клиенты», «Заказы», «Аналитика». Видимость каждого пункта определяется прежними правами роли; само меню прав не добавляет. Чтобы воспользоваться инструментом, откройте «Разделы», выберите пункт, затем нужную вкладку/действие. Под заголовком каждого раздела есть короткая подсказка.

| Группа / раздел | Когда и для чего использовать |
|---|---|
| Работа с клиентами — Обращения | Заявка ещё не стала заказом: зафиксировать результат разговора, отказ или повторный звонок. |
| Звонки | Найти звонок/клиента, зафиксировать результат разговора и связать его с заказом. Автоматические события требуют подключённой телефонии. |
| Претензии | Зарегистрировать недовольство клиента, назначить ответственного, оформить решение. |
| Повторная стирка | Следить за исправлением заказа после претензии. |
| Финансы — Касса | Водитель видит доставки и свои наличные за день, нажимает «Передал в кассу». Администратор раскрывает доставки каждого водителя и нажимает «Принял денежные средства». Внизу свёрнут «Итог месяца» с автоматическим закрытием. [Инструкция](cash.md). |
| Скидки и лояльность | Настроить промокоды, сроки и правила скидок. |
| Начисления и KPI (ранее Мотивация) | Посмотреть сдельные ставки, начисления за операции и показатели операторов. |
| Производство — Материалы (ранее Склад) | Остатки моющих средств и расходников, нормы и движения. Это отдельный учёт; ковры клиентов находятся на этапах «Склад» и «Готовы к доставке» в заказах. |
| Планирование | Проверить свободные временные окна и мощность цеха. Назначение заказа выполняет водитель в карточке. |
| Управление и контроль — Управление | Сотрудники/роли, филиалы, тарифы, справочники, шаблоны. |
| Сводка по заказам | Показатели за период: помыто, доставлено, остаётся на мойке, готово к отправке; изделия и суммы раздельно. |
| Просрочки и эскалации | Проверить задачи по задержкам и открыть связанный заказ. Автоматическое создание требует работающего worker. |
| Заявки на удаление, Корзина, Журнал аудита | Проверка ошибочных заказов, мягкое удаление/восстановление и история действий. |
| Сервис — Интеграции | Подключения внешних сервисов, импорт и журнал отправки сообщений. Автоматическая отправка outbox требует worker, которого нет на текущем бесплатном web. |
| Экспорт клиентов | Скачать клиентов в CSV или Excel. |
| Очередь отправки | Неотправленные действия/фото на текущем устройстве при проблемах связи; повторная отправка после восстановления сети. |

Оператору ежедневно достаточно принять заявку по телефону/ФИО/адресу и работать с клиентами; изделие и стоимость вносит водитель. Водитель, завсклад, мойщик и упаковщик работают со своим доступным потоком заказов. Дополнительные административные пункты производственным ролям не выдаются.
